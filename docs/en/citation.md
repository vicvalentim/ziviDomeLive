# Citation

ziviDomeLive software, its technical documentation, a future GitBook and a future JOSS paper are **different scholarly/editorial objects**.

## Software

For the software release, use the metadata in `CITATION.cff` as the machine-readable authority.

- software: **ziviDomeLive**
- version: **2.0.0**
- author metadata: recorded in `CITATION.cff`
- software DOI recorded by the project: **10.5281/zenodo.15671506**

Release maintainers must verify the registered Zenodo record before tagging or changing this DOI. Do not mint a different identifier merely to make the documentation look complete.

## MkDocs

This MkDocs site is the official technical documentation for the corresponding software version. It follows the software SemVer and does not currently claim an independent DOI or ISBN.

## Future GitBook

The planned **ziviDomeLive — User & Developer Guide** is a separate didactic/editorial publication. It has no DOI or ISBN until a real publication/registration process assigns them.

## Future paper

A future JOSS or other peer-reviewed paper will have its own editorial citation/DOI if and when published. That identifier must never replace the software DOI in `CITATION.cff`.
