# Citação

O software ziviDomeLive, sua documentação técnica, o futuro GitBook e um futuro artigo JOSS são **objetos acadêmicos/editoriais distintos**.

## Software

Para a release do software, use `CITATION.cff` como autoridade de metadata legível por máquina.

- software: **ziviDomeLive**
- versão: **2.0.0**
- autoria: registrada em `CITATION.cff`
- DOI de software registrado pelo projeto: **10.5281/zenodo.15671506**

Antes da tag ou de qualquer mudança de DOI, o maintainer deve verificar o registro efetivo no Zenodo. Não crie outro identificador apenas para completar a documentação.

## MkDocs

Este site MkDocs é a documentação técnica oficial da versão correspondente do software. Ele acompanha o SemVer e não declara DOI ou ISBN independente neste momento.

## Futuro GitBook

A publicação planejada **ziviDomeLive — User & Developer Guide** é um objeto didático/editorial independente. Ela não possui DOI ou ISBN até que um processo real de publicação/registro os atribua.

## Futuro artigo

Um futuro paper JOSS ou outra publicação revisada por pares terá citação/DOI editorial próprio se publicado. Esse identificador jamais substitui o DOI do software em `CITATION.cff`.
