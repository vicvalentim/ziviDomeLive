# Prontidão da Release ziviDomeLive 2.0.0

!!! warning "A tag não é um teste"
    Crie `v2.0.0` apenas depois que cada gate aplicável abaixo possuir evidência registrada. Capacidade presente no código não equivale a evidência de qualificação.

Este é o gate final antes de criar `v2.0.0`. Um item marcado significa que existe evidência; não significa apenas que o recurso existe no source.

## 1. Automated

- [ ] clean/test/build passa
- [ ] `qualificationTests` passa
- [ ] validação documental passa
- [ ] MkDocs strict EN/PT passa
- [ ] `buildReleaseArtifacts` passa
- [ ] estrutura final do pacote validada

## 2. GPU visual

- [ ] Standard
- [ ] Domemaster
- [ ] Equirectangular
- [ ] Skybox
- [ ] CalibrationTool
- [ ] contrato visual de Environment
- [ ] troca representativa de resolução / `resetGraphics(int)`

## 3. Benchmark

- [ ] smoke do BenchmarkTool
- [ ] baseline CPU
- [ ] modo de medida CPU/GPU implementado pela ferramenta corrente
- [ ] relatório arquivado com ambiente exato

## 4. Native output

- [ ] receiver NDI em cada plataforma declarada
- [ ] receiver Syphon no macOS se macOS for declarado
- [ ] receiver Spout no Windows se Windows for declarado

Não deduza qualificação Linux/macOS/Windows apenas da compatibilidade do source.

## 5. Pacote Processing instalado

- [ ] instalar ZIP/PDEX gerado em sketchbook limpo
- [ ] abrir `reference/index.html`
- [ ] source incluído conforme planejado
- [ ] seis learning examples abrem/executam
- [ ] CalibrationTool abre/executa
- [ ] BenchmarkTool abre/executa
- [ ] pacote sem testes ou relatórios gerados de benchmark

## 6. Publication metadata

- [ ] `library.properties` validado
- [ ] ZIP/TXT/PDEX estáveis gerados juntos
- [ ] README/MkDocs/CFF/Zenodo consistentes em versão/DOI
- [ ] claims de plataformas testadas correspondem à evidência
- [ ] DOI/ISBN documental ausente/null até registro real

## 7. Freeze

- [ ] CHANGELOG representa a implementação realmente entregue
- [ ] roadmap não é descrito como capacidade corrente
- [ ] termos deprecated 1.x não contaminam tutoriais 2.0 salvo notas explícitas
- [ ] nenhum claim genérico VR/headset/stereo runtime permanece sem contrato implementado
- [ ] nenhuma mudança de renderer/API foi feita apenas por conveniência documental

Somente depois das evidências aplicáveis o maintainer cria `v2.0.0`.
